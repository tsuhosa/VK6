# 🌸 Vân Khánh Diary

Game quản lý thời gian kể về Vân Khánh — du học sinh Việt Nam ở Trung Quốc, tự lo cuộc sống và viết luận văn để tốt nghiệp.

## 🎮 Cách chơi

- Mỗi ngày game = **4 phút thực** (24 giờ)
- Chọn hành động: Ăn, Ngủ, Làm thêm, Học, Viết luận, Chơi
- Quản lý **HP**, **SP**, **Kiến thức**, **Luận văn**, **Tiền**
- **Luận văn = 100%** → tốt nghiệp

## 📖 Cốt truyện

**Chương 1 — Thạc sĩ · Bắc Kinh · CNU**
**Chương 2 — Tiến sĩ · Thượng Hải · SISU**

Bố mẹ và em gái sẽ bay sang Thượng Hải dự lễ tốt nghiệp.

## ⚡ Tối ưu iOS

- 12fps logic, 3fps UI
- Cache DOM, không rebuild
- Dừng khi tab ẩn
- Auto-save 10s
- **Không nóng máy**

## 🚀 Cài đặt

Upload lên GitHub Pages hoặc chạy `npx serve .`
